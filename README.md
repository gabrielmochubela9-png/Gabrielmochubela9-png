- Responsive, keyboard-accessible interface
- Modular file structure and a README for each project

## Engineering approach

1. **Understand the process first.** I map how the work is done today before writing code.
2. **Keep it simple and reliable.** I choose proven tools over complexity.
3. **Build in security and access control early.**
4. **Document as I go.** Every project has setup instructions, structure notes and customisation guidance.
5. **Make it easy to extend.** New features should fit into the existing structure without rewrites.
